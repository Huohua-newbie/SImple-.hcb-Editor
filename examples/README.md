# 示例剧本 DSL 指令说明

本目录的 [`case0.txt`](case0.txt) 是 HCB 剧本编译器的输入示例。剧本为 UTF-8
编码的文本，编译时由 [`hcb_builder.parser`](../hcb_builder/parser.py) 逐行解析。

## 基本规则

剧本支持三种行：

- **注释行**：以 `#` 开头，编译时忽略；
- **标签行**：以 `::` 开头，用于跳转目标，如 `::loop`；
- **指令行**：`[指令,参数...]` 形式，参数以英文逗号分隔。

> 注意：注释必须**独占一行**（行首为 `#`），不能写在指令行末尾。

## 指令速查

| 指令 | 格式 | 说明 |
| --- | --- | --- |
| `bg` | `[bg,编号]` / `[bg,编号,差分]` | 设置背景图 |
| `bgm` | `[bgm,编号]` | 播放 BGM |
| `bgmstop` | `[bgmstop]` | 停止 BGM |
| `se` | `[se,编号]` / `[se,编号,loop,时长]` / `[se,编号,end,时长]` | 播放音效 |
| `msg` | `[msg,middle\|normal\|boxin\|boxout]` | 对话框位置 / 显隐 |
| `cha` | `[cha,角色名]` / `[cha,角色名/显示名,语音编号]` | 设置说话人 |
| `dia` | `[dia,文本]` | 显示对话内容 |
| `cgload` | `[cgload,CG名]` | 加载 CG（须在 `[start]` 之前） |
| `cg` | `[cg,CG名]` / `[cg,CG名,x,y,zoom,time]` | 显示 / 设置 CG |
| `chaload` | `[chaload,真实名,编号:显示名,...]` | 动态定义说话人函数（须在 `[start]` 之前） |
| `bs` | `[bs,cha,pose,cloth,face,l,'l/m/r',z,x,y,lyr]` | 设置立绘 |
| `bsfade` | `[bsfade]` | 清除当前立绘 |
| `sel` | `[sel,start,标题]` / `[sel,op,选项,目标]` / `[sel,end]` | 选项系统 |
| `jump` | `[jump,::标签]` | 无条件跳转 |
| `start` | `[start]` | 脚本开始标志（展开为头部模板） |
| `end` | `[end]` | 脚本结束标志（展开为尾部模板） |
| `white` | `[white]` | 白屏 |
| `eyecatch` | `[eyecatch]` | 转场效果 |

## 各指令详解

### bg — 背景

```text
[bg,编号]
[bg,编号,差分]
```

- `编号`：查背景表 `BG_LIST`，得到对应引擎 function 地址；
- `差分`：可选，背景的细分版本编号。

不带差分参数时使用默认构图（第八个入参为 `-1`）。

### bgm / bgmstop — BGM

```text
[bgm,编号]      # 播放指定编号的 BGM
[bgmstop]       # 停止当前 BGM
```

`编号` 为 1-255 之间的整数。

### se — 音效

```text
[se,编号]              # 单次播放
[se,编号,loop,时长]     # 循环播放
[se,编号,end,时长]      # 停止循环（带收尾时长）
```

- `loop`：进入循环播放，`时长` 为循环相关时间参数；
- `end`：结束循环，`时长` 为收尾时间参数。

### msg — 对话框

```text
[msg,middle]    # 居中显示（引擎入参 (1,-1)）
[msg,normal]    # 通常位置（引擎入参 (0,nil)），并强制恢复对话框显示
[msg,boxin]     # 显示对话框（引擎入参 (0,nil)）
[msg,boxout]    # 隐藏对话框（引擎入参 (1,-2)）
```

### cha — 说话人

```text
[cha,角色名]                      # 本名显示，无语音
[cha,角色名/显示名,语音编号]        # 指定显示名与语音
```

- `角色名` 须存在于角色表 `CHA_LIST`；
- `显示名` 支持：
  - 角色预设别名（如 `索尔/一磨`）；
  - `？？？`：隐藏说话人姓名；
  - 未预设的名字按本名处理。

### dia — 对话

```text
[dia,文本]
```

文本以引擎字符串编码（GBK）写入字节码，可以包含游戏特殊标记
（如 `[·|那]` 之类的逐字显示控制符）。

### cgload / cg — CG

```text
[cgload,CG名]              # 加载 CG，必须放在 [start] 之前
[cg,CG名]                  # 沿用现有设定显示 CG
[cg,CG名,x,y,zoom,time]     # 指定位置 / 缩放 / 时长显示 CG
```

- `x`、`y`：屏幕坐标；
- `zoom`：缩放，以千分之一为单位，内部换算为 `3000 - zoom*1000`，
  `1` 表示原始大小；
- `time`：淡入时长。

> `[cgload]` 必须在 `[start]` 之前执行，否则该行会被忽略。

### chaload — 动态说话人

```text
[chaload,真实名,编号:显示名,编号:显示名,...]
```

当剧本需要用到角色表 `CHA_LIST` 之外的新角色时，`chaload` 会在脚本正文里
**内联生成一个完整的 SPEAK（名栏显示）函数**，并把它注册进 `CHA_LIST`：

- `真实名`：新角色的本名；
- `编号:显示名`：名义编号到显示名的映射，可有多组；
- 函数内部按名义编号逐项比较，命中则显示对应名字，`-1` 显示 `？？？`，
  未命中兜底显示真实名。

> 同 `cgload`，`[chaload]` 必须在 `[start]` 之前执行。

### bs — 立绘

```text
[bs,cha,pose,cloth,face,l,'l/m/r',z,x,y,lyr]
```

- `cha` / `pose` / `cloth` / `face`：角色、姿势、服装、表情编号；
- `l`：构图状态。`0`=L、`1`=U、`2`=S、`-1`=默认、`-10` 清除当前立绘；
- `'l/m/r'`：预设站位（`l` 左=2、`m` 中=1、`r` 右=0）；
- `z`：深度；
- `x`、`y`：坐标；
- `lyr`：层次（用于多立绘叠放时的前后关系）。

### bsfade — 清除立绘

```text
[bsfade]
```

消费当前立绘缓存并调用引擎函数清除立绘。

### sel — 选项

```text
[sel,start,标题文本]        # 选项开始，渲染标题
[sel,op,选项文本,目标标签]   # 单个选项，选中后跳转到目标
[sel,end]                  # 选项结束，生成分支判断
```

`start` 之后可以跟任意数量的 `op`，最后以 `end` 收尾。编译后生成对全局变量
`G[103]` 的逐项比较：选中第 `i` 项跳到其目标标签，未匹配则回到选项开头。

### jump / 标签 — 跳转

```text
::标签名          # 定义标签（可只定义不跳转）
[jump,::标签名]   # 无条件跳转到标签
```

标签在汇编阶段被解析为脚本内的绝对偏移，跳转占位符随后回填。

### start / end — 开始与结束

```text
[start]   # 脚本开始，展开为头部模板字节（必须）
[end]     # 脚本结束，展开为尾部模板字节（必须）
```

### white / eyecatch — 特效

```text
[white]      # 背景调白
[eyecatch]   # 转场效果
```
